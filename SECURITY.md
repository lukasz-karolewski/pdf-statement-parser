# Security policy

## Reporting a vulnerability

Report vulnerabilities through GitHub's private vulnerability reporting:
https://github.com/lukasz-karolewski/pdf-statement-parser/security/advisories/new

Only you and the maintainers can see the report. Please do not open a public
issue for a vulnerability until there is a fix or a disclosure plan.

## Private financial data

Do not attach real statements to a report. Share redacted
`statement-parser dump` output instead, with names, addresses, account numbers,
and amounts replaced. If a real document is truly needed, say so in the report
and the maintainer will arrange a private transfer.
